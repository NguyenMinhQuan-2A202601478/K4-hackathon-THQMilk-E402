Giai đoạn 3: Thực Thi 3 Tính Năng Core Agent (Multi-Engine Execution)

Parallel Agent Processing

Luồng 1: Tóm Tắt Ngày (Daily Digest)

A
Cron Job Scheduler Trigger

Tự động chạy định kỳ lúc 08:00 (Sáng) & 18:00 (Chiều).

B
Batch Context Aggregator

Gom tin nhắn 24h từ các kênh gán nhãn theo nhóm.

C
LLM Summarization Prompt

Tóm tắt cô đọng 2-3 dòng / thông báo quan trọng.

D
Discord Embed Generator

Tạo thẻ Embed màu sắc theo độ ưu tiên.

Luồng 2: Hỏi Đáp Thông Báo (RAG Q&A)

A
Slash Command `/ask-notice`

Người dùng gõ câu hỏi từ giao diện Discord.

B
Semantic Similarity Search

Tìm top 3 tin nhắn khớp nhất trong Vector DB.

C
Context-Aware Answer Generation

LLM tổng hợp câu trả lời ngắn gọn, chuẩn xác.

D
Citation & Link Source Attribution

Gắn kèm liên kết nhảy trực tiếp đến tin gốc.

Luồng 3: Nhắc Lịch Tự Động (Auto Reminders)

A
Temporal Entity Extraction (NER)

Rút trích Ngày/Giờ, Tên bài tập, Hạn nộp từ văn bản.

B
Task & Deadline Queueing

Lưu lịch vào Scheduler Database.

C
Countdown Alert Dispatcher

Bật thông báo Ping @role trước T-24h và T-1h.

D
Calendar iCal/Google Sync

Xuất link thêm nhanh vào Google Calendar.

Dispatching Rich Messages to Discord Server
4

Giai đoạn 4: Xuất Kết Quả & Tương Tác Học Viên (Discord Delivery & Action Handling)

Discord API / Webhook Integration
Discord Rich Embed Publisher

Đăng các thẻ tóm tắt vào #tóm-tắt-hàng-ngày, #hỏi-đáp-thông-báo, #nhắc-lịch-tự-động.

Interactive Component Handler

Xử lý sự kiện khi học viên bấm nút [ Sync Calendar ], [ Hỏi chi tiết ], [ Nhảy tới bài gốc ].

Feedback & Quality Analytics

Ghi nhận thống kê số lượng tin nhắn đã xử lý, số lượt hỏi đáp và đánh giá độ chính xác của RAG Engine.
